# Documentation

There are three entry points, written for different readers. All describe
the same code.

## [The project explained for everyone](overview-for-everyone.md): no background needed

For anyone, with no medical, engineering or AI background. What a CT scan
is, what the spleen is, what the computer learns, how it is made fast, and
how to read the results, with an FAQ. About 15 minutes.

## [Technical reference](reference/README.md): for experts

For readers who already know deep learning, medical image segmentation and
GPU inference. Covers the exact settings, equations, design trade-offs and
threats to validity. It is concise and does not teach background.

[Data](reference/data.md) · [Architecture](reference/architecture.md) ·
[Training](reference/training.md) · [Inference & evaluation](reference/inference-and-evaluation.md) ·
[Deployment](reference/deployment.md) · [Benchmarking](reference/benchmarking.md) ·
[Code & reproducibility](reference/code-and-reproducibility.md) · [Colab](reference/colab.md)

## [Learning track](learn/README.md): from first principles

For a software engineer with an electrical-engineering background who wants
to understand everything in this repository: the medicine, the physics, the
maths, the machine learning and the GPU engineering. It builds up step by
step, uses analogies to signals and software, and ties every idea back to a
line of code.

[Start here](learn/README.md) → 13 chapters + [glossary](learn/glossary.md)
